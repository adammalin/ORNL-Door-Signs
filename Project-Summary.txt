EDITOR AND PRINT
Static HTML/CSS/JavaScript; no public runtime service, analytics, external fonts or account. Organization/title/subtitle/group/room editing, title sizing, text auto-fit, gallery search/category/science-area filters, crop pan/zoom, canvas and keyboard interaction, undo/redo, local autosave, JSON save/reopen, native PNG/PDF downloads and visible fallback save links.
Physical size: 8.5 x 5 inches. The supplied examples measure 2550 x 1650 (8.5 x 5.5 despite their filenames); the app follows the requested 8.5 x 5 size.
PNG: 2550 x 1500 pixels, 300 dpi metadata. PDF: 612 x 360 pt with identical losslessly compressed RGB artwork. Print at Actual size / 100%. No bleed, crop marks, CMYK or PDF/X. Invalid text or a crop below 300 effective photo dpi blocks print exports.
The original starter public image is the campus PHOTO layer from the supplied medium DVCD PSD, explicitly approved by Adam on November 18, 2026. The template leaf remains the original transparent layer. Mulish is locally hosted under its included OFL.

TUTORIAL
Eight steps highlight the real size/text/gallery/crop/quality/save/export controls. Opens once per browser profile, records dismissal, and replays only from Tutorial or an explicit agent command. Back/Next/Skip/Close/Finish, keyboard Escape and focus restoration are supported. Storage-unavailable sessions retain manual replay.
